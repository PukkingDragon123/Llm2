Place licensed font files here (copy from a Windows PC: C:\Windows\Fonts):
  cambria.ttc, cambriab.ttf, cambriai.ttf, cambriaz.ttf   (Cambria - used by the whole quotation)
  angsa.ttf / ANGSANA.TTC                                 (Angsana New - footer)
The PDF renderer (LibreOffice) will then use the exact fonts of the original quotation. Without them it uses
metric-compatible substitutes (Caladea for Cambria, Liberation Serif for the footer).
