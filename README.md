# Prolog Titanium Estimator

AI-assisted engineering cost estimation and quotation system for **Prolog Titanium Corporation Co., Ltd.**
It reproduces the company's own costing workbook (FM-SAL-001 quotation workbook: `4. CES`, `Import Price`,
`Import Price (WFN)`, `Domectric Price`, `Labor Cost`, `5. Quotation`, `Disclaimers`) as a traceable calculation
engine, and generates customer quotations from the original Excel sheets used as templates.

## What it does

| Area | Implementation |
|--|--|
| Cost engine | `backend/app/calc/engine.py` — supplier price sheets (freight allocated by value, per-piece `ROUNDUP`), labor-rate table → crew cost (persons × days, per diem, OT, premiums), machine-hour rates (depreciation + consumables + electricity + operator, `ROUNDUP`), part weights (plate / bar / pipe formulas, densities), process hours, outsourced/NDT/finishing services (`MAX(rate × qty, minimum)`), quote items `ROUNDUP(base × (1+OVH+Risk) / divisor, -1)`, CES header price, discounts. Every value is a trace node (formula, numbers substituted, inputs, provenance). Missing inputs become questions — nothing is invented. Arithmetic inputs such as `45000+42000` stay visible in the trace. |
| Verification | The reference project imported from the original `.xls` reproduces Excel's own cached values exactly (55,240 / 21,560 / 68,820 / 1,000; total 146,620; discount 14,662; net 131,958; product line 135,510; all 22 machine rates; all 3 price-sheet totals). |
| Workbook import ("learning from previous projects") | `backend/app/importer.py` reads Prolog FM-SAL-001 workbooks (`.xls`/`.xlsx`): supplier lines & prices, freight formulas, labor salaries & crews, machine table, CES part rows with process hours, services, quotation texts (rich-text red runs, row kinds, heights, page breaks), and builds the supplier price database. Recomputed prices are checked against Excel's cached values. |
| Customer quotation | `backend/app/exports/quotation.py` — built from the original `5. Quotation` + `Disclaimers` sheets (`backend/app/templates/quotation_template.xlsx`, generated by `tools/build_template.py`): same fonts, borders, fills, column widths, row heights, merges, print setup (A4, 95 % / 98 %), print titles, footer `FM-SAL-001 REV.NO.03 EFF.DATE 05/03/25`, logo and certification strip. Body rows are rebuilt from the template's own prototype rows, so any number of lines keeps the original style; totals use live Excel formulas. PDF rendered by LibreOffice. |
| Internal costing | `backend/app/exports/costing.py` — editable workbook in which every number is a live Excel formula (Settings, Labor, Machines, Parts, Services, each price sheet, Summary/CES), verified by recalculating it in LibreOffice and comparing every mapped cell with the engine. Plus a PDF report of the same workbook. |
| Claude | `backend/app/ai/claude.py` (Anthropic SDK, `claude-opus-5-5`, adaptive thinking, structured outputs, server-side refusal fallback, prompt caching). Drawing reading from overview + zoomed tiles per page with page/bbox locations, confidence and explicit unclear items; estimating assistant constrained to factory tables and historical evidence (never supplier prices); quotation text drafting in house style; question consolidation. All AI output is a suggestion the engineer accepts/edits. |
| Engineer review | Extracted drawing rows are accepted / corrected / rejected; only accepted rows become BOM parts (with provenance). |
| History & learning | Actual production costs per category are recorded against the issued revision; calibration factors (actual / estimate) with spread and reliability flag; suggested adjustments per quote item (applied only by the engineer, traced with reason and evidence); similar-project retrieval. |
| Revisions | Issuing a quotation snapshots inputs, results and generated files and increments `REV.n`; revisions can be compared. Issuing is blocked while required inputs are missing. |
| Suppliers | Supplier and price database (seeded from the imported workbook), price age warnings, linking verified prices to price-sheet lines. |

## Desktop app (download)

Every push builds the desktop app on GitHub Actions (workflow **Desktop app**):
Actions → latest run → *Artifacts* → `PrologEstimator-Windows` (contains `PrologEstimator-Setup-<ver>.exe` installer and a
portable zip), `PrologEstimator-macOS`, `PrologEstimator-Linux`. Pushing a tag `v1.0.0` publishes the same files as a
GitHub Release.

- The app runs fully on the computer (local database in `%LOCALAPPDATA%\PrologTitaniumEstimator`), in its own window.
- **Windows with Microsoft Excel installed:** quotation PDFs are printed by Excel itself with the installed Cambria /
  Angsana New fonts — the same renderer and fonts as Prolog's original quotation, so the output is identical to an
  Excel print. Excel is also used to import `.xls` workbooks (it evaluates XLOOKUP).
- Without Excel, LibreOffice is needed for PDF/XLS conversion (https://www.libreoffice.org).
- Claude: Settings → paste the Anthropic API key (console.anthropic.com → API Keys) → **Test connection**. If the key
  cannot use the default model, the app falls back to Claude Sonnet / Haiku automatically. Internet access to
  `api.anthropic.com` is required for AI features; all calculations and exports work offline.

## Run from source

Requirements: Python 3.11+, Node 20+, LibreOffice (`soffice`) and poppler (`pdftotext`, for tests).

```bash
cd backend && pip install -r requirements.txt
```

```bash
cd frontend && npm install && npm run build
```

```bash
cd backend && uvicorn app.main:app --host 0.0.0.0 --port 8000
```

Open http://localhost:8000. Data (SQLite DB, uploaded drawings, generated files) is stored in `data/`
(`PROLOG_DATA_DIR` to change). The first start seeds the factory rate tables and the reference project from
`backend/app/seed/reference_import.json` (imported from `reference/QT-2608533_Rev.4_…xls`).

Claude: set `ANTHROPIC_API_KEY` (or enter a key in **Settings**; stored in `data/ai_config.json`, mode 600).
Model override: `PROLOG_CLAUDE_MODEL`.

Exact fonts: copy Cambria and Angsana New font files into `backend/fonts/` (see the README there) so the
PDF renderer uses the original fonts; otherwise metric-compatible substitutes are used.

the fidelity measurements in `docs/VERIFICATION.md`. `tools/eval_drawing_extraction.py` scores Claude's drawing
extraction against `reference/drawing_truth_PTC2211120.json` (needs an API key).
